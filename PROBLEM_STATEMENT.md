# Problem Statement

## Title

SDLC Multi-Agent Assistant for Automated Backend Project Generation

## Problem

Most AI tools can generate code snippets or chatbot responses quickly, but they do not reliably support the complete software development lifecycle. A user may get code from an AI model, but still struggle with:

- converting vague requirements into a proper project structure,
- generating testable and organized backend files,
- validating correctness,
- preparing deployment artifacts,
- handing the output to developers, testers, or non-technical stakeholders.

Because of this, there is a gap between "AI can answer" and "AI can help deliver a software project in a structured way."

## Proposed Solution

Build a multi-agent SDLC assistant that transforms a natural-language requirement into a backend starter project through role-based agents. Instead of returning only chat output, the system coordinates multiple responsibilities such as project analysis, code generation, testing, and delivery.

## Objective

To design a multi-agent system that helps a user move from idea to implementation by generating:

- backend code,
- API endpoint structure,
- validation tests,
- deployment-ready handoff assets.

## Target Users

- students and interns learning backend development,
- non-technical users who want a software prototype,
- testers who need structured outputs to validate,
- junior developers who need a starting project scaffold.

## Innovation

The key innovation is that the system is positioned as an SDLC assistant rather than a generic AI chatbot. Its value comes from orchestration, separation of responsibilities, and production-oriented outputs.

## Expected Impact

- reduce time from idea to working project scaffold,
- make backend generation more structured and understandable,
- improve project handoff between roles,
- demonstrate a realistic use of multi-agent AI in software engineering.

## Short Version For Viva Or Interview

This project solves the problem that normal AI chat tools generate code quickly but do not manage the workflow of software development. My system uses multiple agents to convert a user requirement into a build-ready backend starter project with generated code, tests, and delivery assets.
